**Estado:** ⬜ Pendiente

## Objetivo
Toda la interfaz traducible a español, inglés y portugués (Brasil), con la estructura lista para añadir idiomas.

## Pasos

### Paso 1 — Configuración de i18next
- [ ] `i18n/index.ts` con i18next + react-i18next, `fallbackLng: 'es'`
- [ ] `i18n/locales/es.json`, `en.json`, `pt-BR.json`
- [ ] Registro único `SUPPORTED_UI_LANGUAGES` (código + nombre nativo) para añadir idiomas en un solo lugar

### Paso 2 — Idioma de Windows
- [ ] IPC `app:getLocale` → `app.getPreferredSystemLanguages()` / `app.getLocale()`
- [ ] Opción "Usar el idioma de Windows" que mapea al idioma soportado más cercano, o `es` si no hay coincidencia

### Paso 3 — Extraer textos
- [ ] Sidebar, Toolbar, Player, TranscriptView, BottomBar, TitleBar
- [ ] Vistas Configuración y Cola
- [ ] Mensajes de error y toasts
- [ ] `aria-label` también traducidos

### Paso 4 — Lista de idiomas de Whisper
- [ ] `src/shared/whisperLanguages.ts` con los ~99 códigos de Whisper
- [ ] Nombres con `Intl.DisplayNames([uiLang], { type: 'language' })`, ordenados alfabéticamente
- [ ] "Detectar automáticamente" (`auto`) al inicio

### Paso 5 — Pluralización y formatos
- [ ] Plurales ("1 pendiente" / "3 pendientes")
- [ ] Fechas relativas de los grupos del historial traducidas

### Paso 6 — Verificación
- [ ] Recorrer la app en los 3 idiomas
- [ ] Commit: `feat(i18n): es, en, pt-BR`
- [ ] **Cierre de Fase 1**: `npm run dev` funciona

## Criterios de aceptación
- [ ] Cambiar el idioma actualiza la UI sin reiniciar
- [ ] Ningún texto visible hardcodeado (buscar cadenas en JSX)
