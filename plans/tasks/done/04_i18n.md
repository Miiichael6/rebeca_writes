**Estado:** ✅ Terminada

## Objetivo
Toda la interfaz traducible a español, inglés y portugués (Brasil), con la estructura lista para añadir idiomas.

## Pasos

### Paso 1 — Configuración de i18next
- [x] `i18n/index.ts` con i18next + react-i18next, `fallbackLng: 'es'`
- [x] `i18n/locales/es.json`, `en.json`, `pt-BR.json`
- [x] Registro único `SUPPORTED_UI_LANGUAGES` (código + nombre nativo) para añadir idiomas en un solo lugar

### Paso 2 — Idioma de Windows
- [x] IPC `app:getLocale` → `app.getPreferredSystemLanguages()` / `app.getLocale()`
- [x] Opción "Usar el idioma de Windows" que mapea al idioma soportado más cercano, o `es` si no hay coincidencia

### Paso 3 — Extraer textos
- [x] Sidebar, Toolbar, Player, TranscriptView, BottomBar, TitleBar
- [x] Vistas Configuración y Cola
- [x] Mensajes de error y toasts
- [x] `aria-label` también traducidos

### Paso 4 — Lista de idiomas de Whisper
- [x] `src/shared/whisperLanguages.ts` con los ~99 códigos de Whisper
- [x] Nombres con `Intl.DisplayNames([uiLang], { type: 'language' })`, ordenados alfabéticamente
- [x] "Detectar automáticamente" (`auto`) al inicio

### Paso 5 — Pluralización y formatos
- [x] Plurales ("1 pendiente" / "3 pendientes")
- [x] Fechas relativas de los grupos del historial traducidas

### Paso 6 — Verificación

- [x] **Cierre de Fase 1**: `npm run dev` funciona

## Criterios de aceptación
- [x] Cambiar el idioma actualiza la UI sin reiniciar
- [x] Ningún texto visible hardcodeado (buscar cadenas en JSX)
